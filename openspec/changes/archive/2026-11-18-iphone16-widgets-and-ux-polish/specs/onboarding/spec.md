## ADDED Requirements

### Requirement: OTP keyboard keeps actions reachable
When the OTP field is focused and the system keyboard is visible, Continue and Send code again SHALL remain visible above the keyboard on iPhone 16 and larger phones.

#### Scenario: Keyboard keeps Send code again reachable
- **WHEN** the OTP field is focused and the keyboard is open
- **THEN** Continue and Send code again remain visible above the keyboard on iPhone 16 and larger phones
