## ADDED Requirements

### Requirement: Lock Screen widget families
The extension SHALL offer Lock Screen families via a separate `StaticConfiguration` widget: `accessoryCircular`, `accessoryRectangular`, and `accessoryInline`, showing today’s word from the App Group store.

#### Scenario: Add Lock Screen widget
- **WHEN** the user customizes the Lock Screen and searches for MiBar
- **THEN** circular, rectangular, and inline MiBar widgets are available and show today’s word
